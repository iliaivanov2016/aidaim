Peer-To-Peer Demo
=================

This demo presents how to build peer-to-peer messenger.

Active property of a client is managed by Start and Stop buttons.
Incoming connections are allowed when client is started.
To set direct connection between two clients, you must have Active property set to True on both sides. 
If a client is already connected, Active property takes no effect on the data exchange.
Sending messages to itself (from User1 to User1) will show an error message.

Read MsgCommunicator Manual for details.
