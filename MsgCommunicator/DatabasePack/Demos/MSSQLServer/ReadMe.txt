MsgCommunicator Database Demos for MySQL
============================================

You should install the following products by AidAim Software which
you can download from http://www.aidaim.com/products/download.php#MSG
web-site:
- MsgCommunicator v.4
- MS SQL Server Database Module for MsgCommunicator (Source\MSSQLServer)

Please do not forget to set the ConnectionString property of TADOConnection components in both Client and Server projects 
before running demos.
