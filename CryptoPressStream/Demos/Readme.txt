			Demos Description
			=================

  Demos folder contains some simple examples of using CryptoPressStream.


BinToString
===========
  This demo shows how to convert binary data to string (HEX UPPER, HEX LOWER, MIME64, UU, XX).

BLOBFields
==========
  This example shows how to compress blob fields using CryptoPressStream.

Buffer
======
  This is an example of buffer compression and encryption.

File
====
  This demo illustrates how to compress and decompress file in easiest way.

FastMemoryStream
================
  Proves that TCPSMemoryStream is much faster then TMemoryStream on writing new data.

LoadSave
========
  Shows how to save and load different types of data in most easy way.

ManyFiles
=========
  This demo shows how to create archive from many files and view images file stored there.

Network
=======
  Example of transmitting data via network in compressed and encrypted form.

RijndaelEncryption
===============
  Show how to encrypt buffer using Rijndael algorithm (AES).
  This demo proves full encryption compatibility with NIST recommendations.

Streams
=======
  This is a demo project that show how to use CryptoPressStream streams.

String
======
  This demo illustrates how to compress and encrypt strings.

StringToFormat
=============
  This demo shows how to convert string to one of the following formats: 
  HEX UPPER, HEX LOWER, MIME64, UU, XX.

UnicodeFileName
==============
  Example of use of Unicode file names in TCPSFileStream.
