- version 6.30 (02/22/2008)

  New features added: 
  1. New SQL functions were added:
     - ABS
     - CEILING, CEIL 
     - FLOOR
     - MOD
     - POWER, POW
     - RANDOM, RAND
     - ROUND     
     - SIGN
     - TRUNCATE,TRUNC
     - HEX
  2. New SQL operators were added:
     - %, mod (same as MOD(x,y))
     - shl, << (shift left)
     - shr, >> (shift right)
     - xor, ^  (bitwise XOR)
     - &  (bitwise AND)
     - |  (bitwise OR)
     - ~  (bitwise NOT)
  3. Hex constants are now supported (both C++ and Delphi forms: 0xff and $FF)
  4. C++ form of logical and comparison operators is now supported (!, &&, !=, ==).
  5. Compatibility with BDE Paradox in TEasyTable.ExportTable and DBTransfer utility improved.

  Bugs fixed:
  1. Bug with AVG operator on currency fields fixed.
  2. Bug in subquery containing quoted or bracketed strings was fixed.
  3. Problem with editing / inserting records on dataset filtered by memo fields was solved.
  4. Memory leak problem in BlobsSQL demo was solved.

  2. Single file database stability on files > 2 Gb was improved.
  3. TETManager utility was essentially improved:

     - Fields and indexes tabs added to show structure of the opened dataset.
     - Create and restructure table form redesigned
     - RecNo / RecordCount display added for fields and indexes tables.

  1. Problem with Real type in progress events in C++ Builder was solved.

  2. Bug with setting table names from BDE in DBTransfer utility was fixed.
  3. Bug in SUM and AVG functions with NULL arguments was fixed.
  4. Problems with datasets filtered on memo fields were solved.

- version 5.00 (12/20/2002)

  New features added: 
  1. EasyTable is now thread-safe. TEasySession component is added.
  2. DatabaseFileMode property is added to TEasyDatabase component. 
     If you need to store small tables, use dfmCompact database file mode 
     (less than 10 Kb in size for a database file containing simple table). 
     For large databases use dfmLarge mode. Default mode is dfmNormal.
  3. Maximum field name and index name length is now 253 chars. 
     Database file format is changed. Databases of EasyTable 5.00 format
     cannot be opened by previous EasyTable versions. 
     Database files of previous EasyTable versions can be handled by 
     EasyTable 5.00 without converting.
  4. SQL: new string functions are added: SUBSTRING, LENGTH, POS.
  5. SQL: date-time functions are implemented: 
          SYSDATE, NOW, CURRENT_TIMESTAMP, CURRENT_DATE, CURRENT_TIME, 
          TOSTRING, TODATE.
  6. SQL: MEMORY option is added to work with in-memory tables.
  7. SQL: CAST function is added.
  8. SQL: LastAutoInc function is added.
  9. Deleting of auto-indexes is now allowed.
  10.TETManager now allows to change table fields order.
  11.AutoInc value is now unsigned integer and can be changed up to 2^32.
  12.New method TEasyDatabase.MakeEXEDatabase is added. 
     Now EasyTable database can be attached to executable file and 
     handled there in read-only mode. 

  Changes:
  1. Default value of TEasyTable.AutoIndexes is now False.
  2. Use TEasyTable.CacheEnable property instead of TEasyTable.FastOpen is recommended.

  Bugs fixed:
  1. SetKey error message for incorrect index is now meaningful.
