How to run
------------

1) Open DBFetch.sln in Visual Studio and compile it 

2) Install EasyTable ODBC Driver. See Installation chapter in the product readme.txt

3) Create User DSN with name EasyTable_DBFetch and specify a path to the dbfetch.edb file 
in this test folder

4) Run DBFetch
