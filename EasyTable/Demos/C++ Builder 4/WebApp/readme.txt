WebApp demo
===========

   Important!!!

1. If you have trial version of EasyTable, get iserver.dll 
   which is compiled with commercial EasyTable from 
   www.aidaim.com/download/tet_free/iserver.zip 
   as the nag-screen limitation 
   will not allow you just to compile and use this demo
   with IIS.

   If you have commercial version of EasyTable, you can 
   compile the source code of this demo (see src.zip).

2. Place iserver.dll into your web server scripts directory.

3. Copy file Demos\Data\DBFishes.edb into your web server 
   scripts directory.
   Important note!! Database in IIS Scripts folder can only 
   be accessed in read-only mode. 

4. You can then access this application  from a web browser
   using http://<your web server>/scripts/iserver.dll
