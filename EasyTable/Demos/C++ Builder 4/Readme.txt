Demos Description
=================

 Demos folder contains some simple examples of using EasyTable.

Base
====
  This example demonstrates how to create table and 
 shows simple record operations: insert / edit / delete record.


Batch
=====
  This example the batch operations of EasyTable via AddRecords method.


Blobs
=====
  This program illustrates how to create table with blob fields and 
 demonstrates simple operations with the blobs.


DBFlyTreeView
=============
  This demo shows how you can use EasyTable with DBFlyTreeView. You should 
 install both products before opening this demo project. DBFlyTreeView is a 
 product of our partner, Imca Systems.
 Web site: http://www.imcasys.com.


EncryptDB
=========
  This sample illustrates how to work with encrypted database.


Encryption
==========
  This application shows how to work with encrypted tables.


ExeDatabase
===========
  This program demostrates how to create executable file (EXE) merged 
 with EasyTable database (EDB).


FastReport
==========
  This demo shows how you can use EasyTable with FastReport VCL. You should 
 install both products before opening this demo project. FastReport VCL is a 
 product of our partner,  FastReport Software.
 Web site: http://www.fast-report.com
 Please download FastReport trial version from this site.


Filter
======
  This demo illustrates filtering records and 
 shows how to find records matching specified search criteria by
 FindFirst and FindNext methods.


FindKey
=======
  This example demonstrates finding records by FindKey, FindNearest,
  GotoKey and GotoNearest methods.


FishFact
========
  This application shows how to display Paradox style memo and graphic
 fields in a form. 


InMemory
========
  This program illustrates how to use in-memory tables. 


ManyToMany
============
  This sample shows how to set many-to-many relationship using 
 EasyTable components. The application displays Departments and Members,
 where each member works in one or more Departments.


MasterDetail
============
  This demo shows how to use tables with master-detail relationship. 


MergeDBExe
============
  This demo shows how to merge EasyTable database file and executable file.
  Many thanks to Andreas Greuer who sent us an original demo for C++ Builder.


MultiThread
============
  This demo shows how to use EasyTable in multi-threaded environment. 


QuickReport
===========
  This example demonstrates how to use QuickReport with EasyTable.


Range
=====
  This application shows how to set range on records.


Search
======
  This sample demonstrates searching records 
 by Locate and Lookup methods.


Share
=====
  This demo illustrates navigation and other operations 
 in 2 EasyTable components which use one underlying physical table.


Sort
====
  This application shows how to sort records.


SQL
===

  For examples of SQL queries, see Utils\Bin\*.sql files. These queries can 
 be tested using SQLConsole utility.


Jpeg
====
  This demo shows how you can use JPEG images with EasyTable.


WebApp
======
  This application demonstrates how to use EasyTable in 
 web application (ISAPI dll).
