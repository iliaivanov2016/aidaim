How to run
----------

1) Use DSN named 'acr' pointed to "..\Data\test.adb".
   Detailed instruction on how to create a DSN you can find in "..\Test\ReadMe.txt".

2) Configure your internet server (Apache, IIS, or other) to work with php.

3) copy sql_odbc.php to the root directory of your server.

4) Open sql_odbc.php page in your browser (http://127.0.0.1/sql_odbc.php 
   for local configuration).

5) Press 'Execute SQL Script' button.
