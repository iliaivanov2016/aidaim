How to run
----------

1) Use DSN named 'acr' pointed to ..\Data\test.adb
   Detailed instruction on how to create DSN you can find in ..\Test\ReadMe.txt

2) In Excel:
   - Data -> Import -> Import data -> New connection
   - In Master:
     - Select "New Connection", press "Next" button
     - Choose DSN named "acr" from the list, press "Next"
     - press "Next" several times and "OK" till the data be inserted

3) Excel works with ODBC Driver by 2 different ways.
   To test another one:
   - Close then reopen Excel
   - Data -> Import -> Import data
   - Select "test.adb Table1" data source
   - press "OK"
