How to run
------------

1) Install Accuracer ODBC Driver. See Installation chapter in the product readme.txt

2) Create User DSN with name Test and specify a path to the test.adb file 
   in this test folder

3) Create Database Alias with name Test and specify the DSN you created

5) Open test.dpr in Delphi and compile it 

6) Run test.exe and click Open Database buttons

Note, Graphic fields are not supported yet.
