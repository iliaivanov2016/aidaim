This demo shows how to import table with blob fields from MySQL to Accuracer.

This project requires MySQLDAC components for compiling.
You can download them from http://www.microolap.com/
MySQL database server must have dbdemos database with biolife table to run this project
(you can download database creation SQL script from http://www.microolap.com/).

How To Use:

1) You should create 'dbdemos' MySQL database before running this program - 
   run file create_dbdemos.bat.
2) Compile and run program. 
3) Click on Connect button, select your host and other MySQL settings and click OK.
4) Now you can Import data to Accuracer using ImportData button.
