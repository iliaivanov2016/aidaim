			Demos Description
			=================

  Demos folder contains some simple examples of using Accuracer.

  For examples of SQL queries see Utils\SQLConsole\SQL\*.sql files. 

  These queries can be tested using SQLConsole\ACRManager utilities:
  http://www.aidaim.com/products/download.php#ACR  



Autoinc
=======
  This demo demonstrates the advanced abilities of autoincrement fields.


Base
====
  This example demonstrates how to create table and 
  shows simple record operations: insert / edit / delete record.


BatchMove
=========
  This demo shows how to perform batch operations using TACRBatchMove component.


Blobs
=====
  This program illustrates how to create table with blob fields and 
  demonstrates simple operations with the blobs.


BlobsSQL
========
  This program illustrates how to insert and update blob fields via SQL statements.
  Also this is an example of Params usage.


ChangesDetectionMultiUser
=======================
  Shows how to detect changes made by other sessions.


Client
======

  This program shows how to connect from client to a remote database server 
  using TACRDatabase and TACRTable components. Compression
===========
  This demo show how to compress BLOB and varchar fields. 


CreateDatabase
==============
  This sample illustrates how to create database.

CSVImport
=========

  This program shows how to import data from text files in CSV format
 to Accuracer.

DBFlyTreeView
=============
  This demo shows how you can use Accuracer Database System with DBFlyTreeViewPro. 
  You should install both products before opening this demo project. 
  DBFlyTreeViewPro is a product of our partner, 9Rays.Net.
  Web site: http://www.9Rays.net


DefaultMinMax
=============
  This demo shows how to set default, minimum and maximum field values in Accuracer.


EncryptedDB
===========

  This demo demonstrates how you can encrypt your database files.

ExceptionHandling
=================

  This demo shows how to handle exceptions like key violations, post and delete errors.

ExeDatabase
===========
  This program demostrates how to create executable file (EXE) merged 
 with Accuracer database (ADB).


ExportToSQL
===========
  This demo shows how to export tables to SQL Script.


FastReport
==========
  This demo shows how you can use Accuracer Database System with FastReport VCL. 
  You should install both products before opening this demo project. 
  FastReport VCL is a product of our partner, FastReport Software.
  Web site: http://www.fast-report.com


Filter
======
  This demo illustrates filtering records and 
  shows how to find records matching specified search criteria by
  FindFirst and FindNext methods.


FindKey
=======
  This example demonstrates finding records by FindKey, FindNearest,
  GotoKey and GotoNearest methods.


FishFact
========
  This application shows how to display Paradox style memo and graphic
  fields in a form. 


InMemory
========
  This program illustrates how to use in-memory tables. 


Jpeg
====
  This demo shows how you can use JPEG images with Accuracer.

LoadSaveMemoryDatabase
======================
  Example of loading and saving a memory database.

Logging
=======
  This demo is a sample of logging aplication - it writes all changes made in the
  database to log table and to text log. 
  This demo uses events of TACRDatabase component.

ManyToMany
============
  This sample shows how to set many-to-many relationship using 
  Accuracer components. The application displays Departments and Members,
  where each member works in one or more Departments.

MasterDetail
============
  This demo shows how to use tables with master-detail relationship. 

MasterDetailRuntime
===================
  Shows how to eastablish master-detail relationship at run-time.

MemoSearch
==========
  This demo shows how to perform SQL queries and search records on memo fields.

MergeDBExe
============
  This demo shows how to merge Accuracer database file and executable file.
  Many thanks to Andreas Greuer who sent us an original demo for C++ Builder.

MultiThread
===========

  This is a sample of the multi-threaded application. 
  

MySQLImport
===========

  This demo shows how to import data from MySQL.

QuickReport
===========
  This example demonstrates how to use QuickReport with Accuracer.


Range
=====
  This application shows how to set range on records.


RaveReport
==========
  This demo shows how to use RaveReport with Accuracer.

Referential Integrity
================
  This demo illustrates how to create primary and foreign keys for adding
  referential integrity to the database. 

ResturctureMultiThread
===================
  This is an example of restructuring table in a background thread.
  Show how to use TACRDatabase in multi-threaded environment without TACRSession.

Search
======
  This sample demonstrates searching records 
  by Locate and Lookup methods.

SendMessage
===========
  This demo can be used only with CLIENT-SERVER edition of Accuracer (Trial or CS).
  It shows how to send a text message from client to server and vice versa.

Share
=====
  This demo illustrates navigation and other operations 
  in 2 Accuracer components which use one underlying physical table.


Sort
====
  This application shows how to sort records.


SQL
===
  This demo shows how you can run SQL script in Accuracer using TACRQuery component.

Transactions
============
  This demo shows how you can use transactions.

TwoMemoryDatabases
==================
  Demo of using multiple memory databases.

Unicode
=======
  Example of use of the Unicode types in Accuracer. 

UnicodeDatabaseFileName
=======================
  This demo shows how to create database file with Unicode name. 
  It also shows how to create table using AdvFieldDefs property of TACRTable.

UpdateWithoutSQL
================
  This demo shows how to update filtered dataset without using SQL statements.
  It is recommended to use Advanced demo for maximum performance.

WebApp
======
  This application demonstrates how to use Accuracer in 
 web application (ISAPI dll).
