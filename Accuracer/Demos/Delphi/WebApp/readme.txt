WebApp demo
===========

   Important!!!

1. If you have trial version of Accuracer, get iserver.dll 
   which is compiled with commercial Accuracer from 
   http://www.aidaim.com/download/accuracer/iserver.zip
   as the nag-screen limitation will not allow you just to compile and 
   use this demo with IIS.

   If you have commercial version of Accuracer, you can 
   compile the source code of this demo.

2. Place iserver.dll into your web server scripts directory.

3. Copy file Demos\Data\DBFishes.adb into your web server 
   scripts directory.
   Important note!! Database in IIS Scripts folder can only 
   be accessed in read-only mode. 

4. You can then access this application  from a web browser
   using http://<your web server>/scripts/iserver.dll
