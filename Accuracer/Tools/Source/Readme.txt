This folder contains source code of Accuracer utilities.
It is recommended to build all of these utilities by Delphi 2010 / XE.

IT IS NOT GUARANTEED that any of these utilities will compile under other versions of Delphi.

If you need compiled utilities you can download them at our web site:
http://www.aidaim.com/products/download.php#ACR

Note 1: if you have purchased a commercial version of Accuracer you should download 
utility Accuracer Database Server from commercial download page, as trial version
of this utility compiled with limit of 5 maximum concurrent connections. 

Note 2: you cannot compile ACR4Convert utility as it requires the special source code version 
of Accuracer v.4 SU. Use compiled binary file.
