Demos Description
=================

  Demos folder contains some simple examples of using SQLMemTable.
 
  For examples of SQL queries see Utils\Source\SQLConsole\SQL\*.sql files. 

  These queries can be tested using SQLConsole utility.


Basic
=====
  This demo shows how to create table and fill it with data.


BatchMove
=========
  This demo shows how to perform batch operations using TSQLMemBatchMove component.


CSVImport
=========

  This program shows how to import data from text files in CSV format
 to SQLMemTable.


ExportToSQL
===========
  This demo shows how to export tables to SQL Script.


LoadSave
========
  This demo illustrates how to load or save SQLMemTable tables.

LoadSaveMemoryDatabase
======================
  Example of loading and saving a memory database.

MemoSearch
==========
  This demo shows how to perform SQL queries and search records on memo fields.


MultiThread
===========

  This is a sample of the multi-threaded application. 

Referential Integrity
=====================
  This demo illustrates how to create primary and foreign keys for adding
  referential integrity to the database. 


TwoMemoryDatabases
==================
  Demo of using multiple memory databases.

Unicode
=======
  Example of use of the Unicode types in SQLMemTable.
